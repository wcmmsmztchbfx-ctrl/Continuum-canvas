# Agent 验证口径

机制回归使用确定性模型 fixture 驱动真实注册表、store、WorkspaceService、Yjs 和素材/生成存储，覆盖契约发现、样式与几何、预演、修订冲突、完整影响集、重启、响应丢失、租约、条件撤销，以及浏览器保存/刷新/回读。这证明实现机制，不证明真实模型理解自然语言的成功率。

真实模型验收入口：

```sh
node scripts/evaluate-agent-v2.mjs --source /absolute/Continuum-canvas --output /absolute/agent-real-model.json
```

该命令明确使用 source 中的 Agent 模型配置，产生模型 API 调用费用。它只读取源配置，在临时目录运行四个自然语言案例，测试画布不使用用户数据，结束删除临时文件；报告只含模型名称、任务轨迹、实际文档与结果，不含密钥。媒体生成预算为零。请在需要真实验收时运行。

案例：三节点横向等距；文字字号与居中；创建画框/标题、归属与连线；媒体引用与提示词。逐例检查命令发现、契约查询、真实字段、回读、零媒体任务，以及人工新增内容在 Agent 撤销后仍存在。真实调用失败、停在澄清、字段不符或工具流程缺失均记录失败；未配置模型记录 blocked，不能算通过。

本机当前没有已启用并配置密钥的 Agent 大模型。因此真实模型验收状态为**待配置**；前端、后端及浏览器 fixture 的通过数另行报告。另有既存环境限制：本机无法绑定测试要求的 127.0.0.2，完整服务端套件需将该环境失败单独列出。
