# Agent 对话与答复

侧栏顶部始终提供「新对话」和「选择对话」。对话属于当前画布；不同对话分别保留历史、草稿、已确认引用和不确定提交的请求编号。切换或关闭侧栏不会停止后台任务。已有记录归入默认对话，新对话从空白上下文开始。

同一对话内，进行中的任务可补充要求；暂停时发送新要求会继续处理，等待选项回答时仍需先回答该问题。任务完成后的下一条消息会创建新任务，带入此前的文字对话。历史工具回执、旧选区和生成授权不会变成新任务的权限；修改已有节点仍以当前选区及本任务创建节点为准。

同一对话保留排队顺序。一段对话等待回答、暂停或等待生成时，不阻止另一段独立对话开始处理；同一画布的执行与写入仍按服务端规则串行协调。

新收到的答复逐字呈现，可点击「显示全文」。历史答复和系统「减少动态效果」模式直接显示完整文本。动画按 Unicode 字素显示，避免拆开中文代理字符或组合 emoji；长答复有最长播放时间，不会让用户等待数分钟。这是已持久化答复的呈现动画，当前没有替换后台请求为实时流式传输。

工具执行达到 24 轮预算后，后台额外进行一次**不带工具**的收尾答复：根据实际回读和提交回执说明完成项与剩余项，然后暂停。收尾失败或返回工具调用时使用已保存事实的保底汇总，不增加画布操作、不增加媒体生成授权、不自动重复调用。已有预算暂停且没有正文的记录也能直接展示保底进度，不会为此重做旧任务。

模型因输出长度限制返回的纯文本会保留，自动进行一次不带工具的正文补全；如果仍未结束，会清楚提示并允许继续补全。截断的工具参数继续拒绝执行。完整答复不会再被静默截为 8000 字符。操作记录较长时折叠展示，最终答复与暂停原因保持可读。

验证使用本地确定性模型、隔离持久化和浏览器 fixture；没有用用户任务发起额外模型调用或付费媒体生成。
