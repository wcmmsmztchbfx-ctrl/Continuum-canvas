# 画布 Agent 使用与维护

## 使用

在画布左侧打开 **Agent**。API 设置中需要分别配置支持工具调用的对话模型、可用的图片或视频生成模型；引用图片还需要对话模型支持视觉输入。

- 输入「帮我生成一个苹果」：Agent 创建节点、填写提示词、提交生成并把结果写回原画布。
- 输入「只写提示词」：可以创建提示词节点，不提交生成。「只做方案，等我确认」则只讨论方案，确认执行前不修改画布。
- 单选或多选图片时，输入框出现候选缩略图；点击单图或「引用全部」才会加入消息。取消画布选择不会移除已确认的引用。
- 遇到关键歧义，问题卡会等待选择或文字回答；关闭侧栏、重新打开网页都不会替用户作答。
- 执行期间的新文字默认补充当前任务。选择「新任务」可在同一画布排队运行。
- 操作、技能、阶段报告和结果可在聊天内查看。点击「定位结果」跳到目标节点。
- 「暂停」停止新步骤，已经提交的生成可以完成；「停止」还会禁止迟到结果自动写回。结果素材仍保留在任务中。
- 「撤销本次操作」只回退本任务中仍能安全撤销的字段；之后手工修改的内容保留。部分失败可继续处理未完成部分，但继续不会自动增加付费次数。

后端在线时关闭网页仍会执行，重开原画布可恢复进度。后端关闭期间不能执行；启动后按持久化回执核对恢复，已提交的生成沿用原请求编号。供应商受理状态不明确时不会自动再发一次。

## 首版边界

- 修改已有内容以发送任务时选中的节点为范围，Agent 新建节点也在本任务范围内。需要调整其他节点时，明确选择并发起相应任务。
- 每次最多引用 4 张图片，模型读取有大小限制的实际预览；生成参考仍使用稳定的原素材身份。附件不会自动成为每张生成图的参考。
- 一个单图目标默认一次生成尝试；单任务最多 12 个输出。增加或重试付费生成需要明确授权，不把「继续」解释成增加额度。
- 单次连续执行有轮数和上下文限制，达到限制会暂停。长任务使用同一后端队列逐步推进，暂不提供多 Agent 并行操作。
- 当前提供内置只读 Skill 列表。自定义 Skill 编辑、插件市场和自动镜头跟随不在本版中。
- 任务停止后保存的迟到结果可查看、下载；不自动复活已删除的节点。
- 同字段冲突保留双方版本，使用现有保存详情中的保留副本、导出和重新载入入口处理。

## 实现边界

`server/agent` 保存任务、工具回执、生成绑定及变更集。模型仅通过已注册且经过校验的结构化工具操作画布。每轮模型输入包含本任务固定版本的基础 Skill，专项 Skill 按需加载。聊天自然语言或附件内的文字不会被解析为命令。

非协作画布使用现有版本化 WorkspaceService；协作画布使用房间的 Yjs 文档与检查点。后台写入、浏览器自动保存以及普通撤销历史共享同步边界。浏览器保留本地相机位置；关闭侧栏不影响同步观察。

生成复用现有 providers、catalogs、jobs、assets 和供应商适配。付费请求发出前再次核验任务与权限；停止、撤销、角色或画布权威状态变化都不能被旧回调绕过。任务资料纳入素材保留范围。

当前前端通过节流轮询读取持久事件，使用单调递增序号更新；浏览器不承担执行循环。后续可替换为事件流而不改变任务持久化与画布写入规则。

## 验证

单元与服务测试覆盖工具结果、图片输入、澄清、暂停/停止、重启、幂等提交、权限、冲突、撤销及生成失败。浏览器测试使用独立临时数据目录、模拟模型和模拟供应商，走真实任务、生成、素材和画布存储链路。

模拟测试验证执行机制，不代表真实模型的理解和画质评测。部署后仍可用小规模真实任务检查所配置模型的工具调用与视觉效果；自动测试不会消耗真实供应商额度。

局域网模式的进度读取也纳入回归：浏览器同源 GET 通常没有 `Origin`，后端可通过本地或局域网 `Referer` 识别读取来源，同时验证连接、登录凭证和协作权限。注册与写操作继续使用独立的权限规则。

浏览器回归可在 PowerShell 中设置 `$env:CONTINUUM_E2E_LAN_AUTH='1'` 后运行 `npx playwright test tests/e2e/smoke/27-agent-runtime.spec.ts`，覆盖局域网授权配置。测试服务依然只监听回环地址，使用独立临时数据和模拟供应商。
